## 未知の変化点を、どこまで再現できればよいか

| 設定 | 確認したいこと |
|---|---|
| Oracle Grid | 真の変化点が候補境界にあるとき、正しく選択できるか |
| Fine-grid | 不要な候補境界を適切に融合できるか |
| Off-grid | 候補境界にない真の変化点へ、どこまで近づけるか |
| No-change | 変化がない係数に偽の変化点を作らないか |

> **相談したいこと：** どの設定を主解析とし、どこからを補足解析にするか。
